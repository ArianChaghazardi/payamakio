## درباره پیامکیو

**پیامکیو (Payamakio)** یک راهکار تجاری، مدرن و سبک برای هوشمندسازی و اتوماسیون سیستم پیامک فروشگاه های اینترنتی ووکامرس است. بسیاری از افزونه های پیامک موجود در بازار به دلیل کدهای قدیمی، عدم بهینه سازی دیتابیس و رابط کاربری پیچیده، سرعت وبسایت را کاهش داده و نرخ تبدیل سفارشات را تضعیف می کنند.

پیامکیو با تکیه بر معماری شیءگرای ماژولار و رابط کاربری تمام صفحه با الهام از دیزاین سیستم های روز جهان (ترکیب قرمز یاقوتی درخشان و دارک اسلیت)، مدیریت ارسال پیامک را متحول کرده است. ارسال با خطوط خدماتی و الگو (پترن)، پیامک های وضعیت سفارش، سیستم اختصاصی بازیابی سبدهای خرید رها شده و موتور تبدیل لید مگنت برای سفارشات رایگان از ویژگی های برجسته این افزونه است.

## ویژگی ها و امکانات کلیدی

1. **طراحی داشبورد تمام صفحه و ریسپانسیو:**
   - پنل مدیریت مدرن سازگار با انواع صفحه نمایش ها (موبایل، تبلت و دسکتاپ).
   - اسکرول افقی لمسی زبانه ها و کارت های گزارش وضعیت زنده.
   - عدم ایجاد هیچ گونه افت رتبه یا پرش چیدمان (Zero CLS).

2. **ارسال فوق سریع با خط خدماتی (پترن / الگو):**
   - عبور تضمینی از بلک لیست مخابرات با سرعت ارسال کمتر از ۳ ثانیه.
   - جایگزینی اتوماتیک متغیرهای داینامیک نام، شماره سفارش، مبلغ و لینک ها.

3. **موتور بازیابی هوشمند سبد خرید رها شده (Cart Recovery):**
   - پایش خودکار سفارشات در انتظار پرداخت یا ناموفق.
   - تولید خودکار لینک پرداخت مستقیم یک کلیکه بدون نیاز به لاگین مجدد.
   - افزایش مستقیم نرخ بازگشت مشتری و فروش فروشگاه.

4. **موتور لید مگنت و سفارشات رایگان (Lead Magnet Engine):**
   - ارسال اختصاصی لینک دانلود فایل و کد تخفیف ترغیب کننده (مانند VIP30) به خریداران محصولات رایگان.

5. **اطلاع رسانی آنی به مدیر فروشگاه:**
   - دریافت سریع پیامک حاوی نام خریدار و مبلغ سفارش بلافاصله پس از ثبت خرید جدید.

6. **سندباکس تست زنده ارسال (Live Sandbox):**
   - قابلیت تست اتصال وب سرویس و صحت الگوها به صورت Ajax مستقیم در پنل مدیریت.

7. **لاگ برداری و تاریخچه اختصاصی:**
   - جدول اختصاصی در دیتابیس برای نگهداری دقیق تاریخچه ارسال ها به همراه کد پیگیری درگاه و وضعیت تحویل.

8. **سازگاری ۱۰۰ درصدی با ووکامرس HPOS:**
   - پشتیبانی بومی از High-Performance Order Storage و عدم وابستگی به متادیتاهای سنگین سنتی.

## سامانه های پیامکی پشتیبانی شده

- **فراز اس ام اس / IPPanel (آی پی پنل):** پشتیبانی کامل از وب سرویس REST پترن های متغیر.
- **کاوه نگار (Kavenegar):** وب سرویس اعتبارسنجی الگویی Lookup با امنیت و سرعت بالا.
- **ملی پیامک (MeliPayamak):** وب سرویس خدماتی اشتراکی BaseService.

## شورتکدها و متغیرهای داینامیک

در متن الگوها و پترن های پیامک می توانید از تگ های هوشمند زیر استفاده فرمایید:

| شورتکد | کاربرد |
| :--- | :--- |
| `{order_id}` | شماره اختصاصی سفارش در ووکامرس |
| `{first_name}` | نام کوچک خریدار |
| `{last_name}` | نام خانوادگی خریدار |
| `{full_name}` | نام و نام خانوادگی کامل خریدار |
| `{order_total}` | مبلغ کل سفارش (تومان) |
| `{items_list}` | عنوان محصولات موجود در سفارش |
| `{payment_link}` | لینک مستقیم و یک کلیکه پرداخت سبد رها شده |
| `{download_link}` | لینک مستقیم دانلود فایل سفارش |
| `{coupon_code}` | کد کوپن تخفیف هدیه برای خریدهای بعدی |
| `{site_title}` | عنوان فروشگاه اینترنتی |
